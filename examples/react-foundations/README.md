# React 基础：阅读清单实验

配套第一篇标杆。React/React DOM 18.3.1、TypeScript 5.7.2、Node.js 22，依赖锁定在package-lock.json。默认不启用StrictMode，无接口、密钥或付费依赖。

```sh
npm ci
npm test
npm run build
npm run dev
```

打开终端显示的示例地址。本站实验室可直接运行App.tsx，无需安装；本地项目需先安装依赖。

## 验证步骤

1. 初始总共2本、已读0、显示2。标记A已读，汇总变1。
2. 搜索React，显示1；清空恢复2。已读汇总针对全部books。
3. 业务ID模式，给A写临时笔记，再反转：笔记仍属于A。
4. 切换key策略会重置清单、搜索和行状态；故障组给A写笔记再反转，笔记落到B。
5. 使用业务ID，给A写笔记并标已读，搜索TypeScript让A卸载，再清空搜索：草稿丢失、已读保留。
6. 只重建列表：行笔记重置，父组件保存的已读状态不变。
7. 每次先重置计数，三次值更新得到1，三次函数更新得到3；事件内快照报告都是0。

草稿是行的局部state，不是持久化功能。刷新后全部数据重置。不要把下标key故障组复制到可重排的业务列表。
