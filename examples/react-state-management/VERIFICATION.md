# 验证记录

核验日期：2026-10-22。

## 已实际执行

环境：本机 macOS，Node.js 22.12.0，React/React DOM 18.3.1。依赖通过本目录 `npm ci` 安装。

- `npm test`：9项通过、0失败。
- `npm run build`：TypeScript 检查与 Vite 6.4.5 构建通过。

用例：

1. Store稳定快照、不可变更新、未修改分支结构共享、无效动作不通知、取消订阅。
2. 缓存同key去重、key隔离、成功结果复用、失效后重取。
3. 手动控制Promise：新请求先结束，旧请求后结束，旧响应不得覆盖。
4. 在途请求失效后，替代请求结果不得被旧响应覆盖。
5. 请求失败保留上次数据，错误可重试恢复。
6. 单次乐观回滚、旧回滚不覆盖新版本、在途读不能覆盖乐观新值。
7. 两个Store实例互不修改对方状态（SSR隔离的必要条件）。
8. React DOM + jsdom：点击按钮触发真实useSyncExternalStore订阅，已读派生数量从0更新为1。

9. 失效或回滚中断的读请求后，不遗留没有有效请求的loading状态。
