# 阅读清单性能实验

Node.js 22，React/React DOM 18.3.1，TypeScript5.7.2。版本锁定见package-lock.json。

```sh
npm ci
npm test
npm run build
npm run dev
```

打开开发服务器输出地址。默认300行，每行44px。

1. 普通行：点击“无关计数加一”，行提交诊断增加。
2. memo+不稳定函数：同样操作仍增加，因为onToggle引用改变。
3. memo+稳定输入：无关计数不使行诊断增加；选择第0本只更新相关行。
4. 固定行高窗口：初始9行，滚到440px有12行；选中状态存父组件，移出窗口再回来不会丢失。
5. tick从0加到1，再点击错误比较按钮，读取0；默认比较按钮读取1。

模式切换会重新挂载列表；搜索重置滚动位置但保留仍在结果中的行身份，诊断应比较每组内部前后差值。layout effect诊断不是全部render尝试次数或性能数据。

Profiler采样：使用npm run dev，选择模式→预热→清空采样→重复固定操作→读取采样。普通生产React默认禁用Profiler，站内无样本时会提示。本例输出是开发构建的渲染时间，不是INP、paint或生产收益。读取结果本身也会引发更新，采用读取前的样本快照。

窗口仅教学：固定高度，不实现动态高度、焦点保留、完整无障碍及浏览器全文查找策略。
