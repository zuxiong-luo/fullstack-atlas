## 核验原则

- 招聘原文只用于需求分析。西门子链接本次返回 406，腾讯、小红书页未返回可读正文，字节页无法获取；不宣称岗位仍在招、不使用列表摘要补造完整 JD。章节按用户提供材料中重复出现的职责安排。个人分析与原始求职文档不随本次发布。
- 先跑代码再写结论。默认确定性本地模型；真实模型适配只供手动配置，未进行付费调用，不把 mock 通过率称为模型效果。
- Tokenizer 固定编码，模型实际上下文上限、消息封装与用量由服务端实际配置和响应决定；字符不等于 token。
- RAG 范围为纯文本、SQLite 和可解释词法基线；不会把假向量包装成语义检索。OCR、真实 embedding、向量库、reranker 留在扩展边界。
- LangGraph 固定安装版本，实际验证审批、拒绝、恢复和重复执行；持久化检查点不等于副作用恰好一次。
- SSE 使用确定性生成器，不声称测过模型首 Token 或大并发。浏览器验证桌面与窄屏；不替代手机真机。
- 数据章只接受有限查询计划，不执行模型输出的任意 SQL；不声称实现通用 NL2SQL。
