未发现阻断本批发布的机制错误。八篇都先交代概念及本章可运行范围，再进入结构、普通执行路径、关键代码与失败边界。第一章是独立 v1 服务；后续是同一 v2 工程按 chapter 参数开放能力，不能理解成八个独立 Git tag 或完整的模型自主规划系统。

## 代码自足与正常/失败路径

决定机制的代码均在正文，出处及下载链接承担追溯和安装职责；读者无需到其他页面找关键实现。02/03/07 已补齐原先容易遗漏的身份映射与 HTTP caller，02 也包含 `evidence_of`。04/05/08 包含 Store/Service/App 的两种语言实现，06 包含实际评测器与数据。

失败路径没有只靠“模型说拒绝”验收：包含非法输入、未知字段、未鉴权、跨 owner、未知工具、坏模型 JSON/结构/引用、上游超时、幂等冲突、过期 epoch、评测失败与容量拒绝。UTF8/BOM/未配对 surrogate 的最终契约已映射到正文实际源码。恢复只承诺本地检查点和 fencing 可证明的范围。
