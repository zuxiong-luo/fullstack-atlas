## 范围与审校

正文约5595汉字（不含代码、表格、参考资料），12节，概念先行；从库存/行锁到原子检查、Redis与Lua关系，再到Stream、数据库事务、支付/关闭和释放Outbox。关键源码直接在正文，外链作出处。Lua独立语法高亮，不把JS模板字符串的单色展示当成Lua高亮。

编写时核对PostgreSQL17事务隔离与锁、Redis EVAL/脚本、XAUTOCLAIM、复制，以及RabbitMQ确认和容量官方文档。独立RabbitMQ与Redis不具有跨系统脚本原子性；实现选择同Redis Lua内预占＋XADD，并明确脚本运行时失败不自动回滚。

自审逐项核对：

- PG固定Read Committed；不将其等待后重检行为推广到其他隔离级别。
- 一人一场一单，即使关闭也不重买；状态与唯一约束一致。
- 金额读取服务端sales；教学函数假设调用者已鉴权，不伪称登录或支付验签已实现。
- 提交与ACK分离；重复编号和不同编号同用户均不重复扣库存。
- XAUTOCLAIM不杀旧worker，测试零空闲仅用于旧处理已经确定结束。
- XLEN限制历史总条数，ACK不删历史；不是ready积压，也不声称全局多副本预算已实现。
- 关闭与释放Outbox同事务；释放按事件ID去重。Redis去重键丢失后重建、写入OOM、真实支付对账均明确未交付。

## 实际运行

macOS14.5 x64；Node22.12.0、PG17.4、Redis7.0.4、pg8.13.1、node-redis4.7.0，精确npm锁文件随包。

    npm ci --ignore-scripts
    npm test

本地首次12/12通过。最终源码格式化后，主代理从实际构建ZIP解压到仓库之外的系统临时目录，重新执行 `npm ci --ignore-scripts --no-audit --no-fund` 与 `npm test`，均退出0，12/12通过。每个ZIP源码文件SHA及命令退出码见 `flash-sale-archive.json`。

11组子场景加父测试：错误GET/DECR负库存、Lua最后一件与重复、20人5件＋峰值2处理器、pg_blocking_pids实检等待、回滚/用户及请求去重、Redis名额高于DB时最终拒绝、历史容量满拒绝、提交后未ACK的真实Redis重启及恢复、支付与关闭竞争、Redis释放成功但DB未标记的重放、Lua错误不回滚。

测试PG只用新建私有Unix socket目录，编号55486；自有Redis只监听127.0.0.1:56390、AOF/appendfsync always。不用用户DATABASE_URL、5432或6379，不执行FLUSHALL。Redis停启使用自有进程SIGTERM，是正常进程停启，不是断电或复制集故障验证。代码在启动/停止状态不确定时保留私有目录并报错。
