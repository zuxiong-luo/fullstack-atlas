## 真实环境与执行

macOS14.5 x64，Node22.12.0 / TypeScript5.7.3 / React18.3.1。`npm ci --ignore-scripts`实际清洁安装12包，audit0；`npm test`先生成App与tsc，再运行Node测试：**10/10通过**。

最短窗口1500组全区间枚举差分；最大值700组逐窗差分及每步候选有效期/严格单调/队首最大检查；next1000组逐项扫描差分；长递增/递减2万项检查每项至多移除一次。

默认[1,3,-1,-3,5,3,6,7]、k3输出[3,3,5,5,6,7]。min预设[2,3,1,2,4,3]/target7返回length2/start4/end6/moves11。next对[2,2,3,1,4]返回下标[2,2,4,4,-1]。

输入先验稠密、安全整数|x|≤10^9、长度≤10^6；正数min额外拒绝0/负数。固定宽度要求1≤k≤n；空数组max拒绝，min/next有空结果。min target为正安全整数。无解min长度0且start/end=-1。

未开observe的min额外标量O(1)，max候选O(k)+输出O(n)，next栈/输出O(n)，时间都O(n)。observer复制数组及累积输出，保留全历史额外可达O(n²)；视图限制32项。
